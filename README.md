# Freedium Reader

A simple Android reader for opening Medium articles in a clean reading interface.

## Features

- Paste a Medium article URL
- Android Share → Freedium Reader
- Clean WebView reading view
- Dark/light mode
- Reading history
- Bookmarks
- Back navigation
- Only the Internet permission
- GitHub Actions automatically builds a debug APK

## Important

This app opens Medium URLs directly. It does not bypass Medium paywalls, authentication, or other access controls.
